# Design token plan

Seed: 1794387642532309344. Five independent rolls use separate PRNG draws.

| Axis | Roll | Reason |
| --- | --- | --- |
| Palette roles | Orange ink with blue evidence | Orange calls attention to decisions, blue distinguishes documentary evidence. |
| Layout | Single column narrative scroll | The public registry reads as an evolving record rather than a wall of widgets. |
| Type | Display serif with grotesk body | Bodoni Moda gives occurrences an editorial presence; Public Sans keeps tasks legible. |
| Motion | Response to action only | Changing a selection or relation communicates cause; ambient motion would compete with evidence. |
| Device | Source margin annotations | Records retain visible attribution next to the identities they support. |

Tokens: orange #EE4D1B, white #FFFFFF, evidence blue #A1DDFF, ink #000000. Orange action controls use black text for contrast. Light is the default for inspecting documents in a working day. Dark mode supports the same task at night. Display type is Bodoni Moda, headings and controls use Public Sans. A 12 column alignment grid supports the single reading column and documentary margin; it never becomes a three card feature grid.

The public opening combines a large editorial headline, an actionable search field and a compact evidence margin. Registry entries are rows. The match workspace is a document comparison with explicit coverage. The sole expressive device is the source annotation system. No animated entrances, decorative metrics, uppercase eyebrows, automatic numbering, glass panels, repeated card shadows or arrow suffixes.
