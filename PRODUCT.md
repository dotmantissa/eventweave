# EventWeave

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Confirmed: React and TypeScript, Fastify and PostgreSQL, npm workspaces. Deploy the web app and API on Vercel. GenLayer Studio hosts the contracts.

## Users
Application builders and incident or release publishers who need to distinguish occurrences, share public evidence and preserve disputed histories.

## Product Purpose
Give public occurrences an identity that survives changes in names without conflating recurring incidents. Applications retain their own outcome rules.

## Positioning
Identity is a bounded, source grounded consensus decision with explicit non merge constraints. Common cause is a separate relation. No event truth, financial compensation or settlement outcome is decided here.

## Operating Context
Register descriptors, attach committed authentic public sources, compare candidate records, challenge merges and reuse finalized identities in independently controlled consumers.

## Capabilities and Constraints
Public software releases, disclosed security incidents and official operational notices. Six records and fifteen pairs per complete docket. Missing evidence remains unknown. Email authentication only. Transactions are abstracted. Private originals and credentials never enter contract inputs.

## Brand Commitments
EventWeave. White, black, orange #EE4D1B and blue #A1DDFF. Human, considerate writing with occasional quiet humour. No emoji, decorative uppercase labels, generic feature grids or unnecessary hyphens. Original woven logo with matching favicon. Light and dark themes.

## Evidence on Hand
The workspace began empty. No adoption, usage counts, customer logos or endorsements are supplied. Public source runs must be recorded separately from controlled tests.

## Product Principles
Evidence keeps its attribution. Unknown is a useful answer. A correction preserves history. Discovery never authorizes reuse. Each consumer controls its own rules.
